# Marketplace Platform

A Laravel 12 marketplace platform where sellers can publish product listings, buyers can place bids, and both parties can communicate through an integrated messaging system.

The project was built as part of my software development portfolio and focuses on authorization, business logic, event-driven architecture, API development, testing, and marketplace workflows.

## Features

### User Roles

* Admin – full platform access
* Seller – create and manage listings
* Buyer – place bids and communicate with sellers

### Marketplace Functionality

* Product listings
* Categories
* Product image uploads
* Bidding system
* Buyer-seller messaging
* Listing management

### Technical Highlights

* Laravel 12
* RESTful API implementation
* API authentication and rate limiting
* PHPUnit unit and feature tests
* Laravel Observers
* Eloquent relationships
* Localization
* Middleware and policy authorization
* Third-party integrations

## Project Status

Active development.

Core marketplace functionality is implemented. Additional features such as shopping cart functionality and payment processing are planned for future releases.
